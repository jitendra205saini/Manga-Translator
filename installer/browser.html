Add the extension to your browser

The translator is installed. One last step: add the browser extension. Extension folder:

Chrome / Edge / Brave

  1. Open chrome://extensions (Edge: edge://extensions).
  2. Turn on Developer mode (top right, Edge: left side).
  3. Click Load unpacked and choose the folder above.
  4. Pin the extension from the puzzle icon in the toolbar.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and choose manifest.json inside the folder above.
  3. Open the extension popup and click Grant site access first.

Firefox removes temporary add-ons when it closes. A signed version that stays installed will be available from the project's GitHub releases.

Use it

  1. Open any manga chapter.
  2. Click the extension icon and switch it ON, or press Alt+T.
  3. First time only: click Add API key in the popup and paste a free Gemini key.
